# Учёт продаж церковной лавки

Одностраничное статическое веб-приложение для учёта продаж товаров церковной лавки. Данные сохраняются в `localStorage`, поэтому можно вести смену без сервера и базы данных. Приложение остаётся обычным HTML-файлом, но при запуске с GitHub Pages, `localhost` или `127.0.0.1` дополнительно работает как PWA.

## Возможности
- Добавление категорий и товаров с ценой и выбором по умолчанию (QR или наличные).
- Ускоренный приём оплаты: выбирайте товар, способ оплаты и регистрируйте продажу одним нажатием.
- Отчёты по товарам и категориям, итоговые суммы по QR и наличным платежам.
- Выгрузка отчёта в CSV для сохранения или передачи бухгалтерии.
- Экспорт и импорт каталога категорий/товаров в JSON для переноса настроек между устройствами.
- Полный экспорт и импорт всех данных приложения: каталог, продажи, журнал операций и служебные метки.
- Сброс смены с очисткой всех продаж.
- Установка на главный экран телефона как PWA при запуске через GitHub Pages.

## Запуск через GitHub Pages
1. Загрузите файлы репозитория в ветку `main`.
2. В настройках репозитория откройте `Settings → Pages`.
3. Выберите `Deploy from a branch → main → /root` и сохраните настройки.
4. После публикации приложение откроется по адресу:
   `https://juriyivanov.github.io/gh/`

Все пути к manifest, service worker и иконкам относительные, поэтому приложение корректно работает из подпапки `/gh/` на GitHub Pages.

Иконки сейчас подключены как SVG-текстовые файлы, чтобы PR не содержал бинарных файлов. Если позже заменить их на PNG, обновите `src` в `manifest.json` и `href` в `index.html`; service worker уже умеет необязательно кэшировать `icon-192.png` и `icon-512.png`, если такие файлы появятся.

## Локальный запуск
Рекомендуемый локальный запуск для проверки PWA-функций:

```bash
python3 -m http.server 8080
```

Затем откройте:

```text
http://127.0.0.1:8080/
```

Также можно открыть `index.html` напрямую как локальный файл (`file://`). В этом режиме основная логика, интерфейс, продажи, отчёты и импорт/экспорт продолжают работать, но service worker не регистрируется, потому что браузеры не поддерживают PWA service worker для `file://`.

## Добавить на главный экран Android/Samsung
1. Откройте `https://juriyivanov.github.io/gh/` в Chrome или Samsung Internet.
2. Откройте меню браузера.
3. Выберите `Add to Home screen` / `Добавить на главный экран`.
4. Подтвердите добавление приложения.

После первого открытия через GitHub Pages браузер сможет закэшировать приложение для последующего офлайн-запуска.

## Работа с данными
- Каталог, продажи и журнал операций сохраняются в `localStorage` браузера под ключом `churchShopDataV1`.
- Для резервного копирования только каталога используйте кнопки «Сохранить список» и «Загрузить список» на вкладке «Настройки».
- Для переноса всех данных используйте кнопки «Экспорт всех данных» и «Импорт всех данных» на вкладке «Настройки».
- Перед полным импортом приложение попросит подтверждение, затем заменит данные в `localStorage` и перезагрузит страницу.
- Для очистки статистики текущей смены нажмите «Сбросить смену». Каталог при этом не изменится.

### Перенос данных из локального файла в GitHub Pages
Старые данные из версии, открытой через `file://`, автоматически не переедут в GitHub Pages-версию, потому что это другой origin браузера.

Чтобы перенести данные:
1. Откройте старую локальную версию через `file://`.
2. На вкладке «Настройки» нажмите «Экспорт всех данных» и сохраните JSON-файл.
3. Откройте GitHub Pages-версию по адресу `https://juriyivanov.github.io/gh/`.
4. На вкладке «Настройки» нажмите «Импорт всех данных» и выберите сохранённый JSON-файл.
5. Подтвердите импорт. Страница перезагрузится с перенесёнными данными.

## Формирование отчёта
На вкладке «Отчёт» доступна сводка:
- таблица по каждому товару: количество продаж и суммы по QR и наличным;
- отдельные таблицы проданных товаров по наличной оплате и QR без пустых строк;
- блок «По категориям» с количеством и суммой по каждой категории;
- итоговые суммы по способам оплаты и общая выручка.

Кнопка «Скачать CSV» сохраняет эти данные в файл с меткой времени, чтобы его можно было открыть в Excel или передать в бухгалтерию.
