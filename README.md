# Учёт продаж церковной лавки

Простое приложение для учёта продаж без сервера и базы данных. Работает в браузере, устанавливается на телефон как PWA и после первого открытия доступно без интернета.

**[Открыть приложение](https://juriyivanov.github.io/gh/)**

## Возможности

- Категории и товары с фиксированной или произвольной ценой.
- Продажа нескольких товаров за одну операцию.
- Оплата наличными или по QR.
- Отдельный учёт продаж по сменам.
- Просмотр и удаление предыдущих смен.
- Итоги по товарам, категориям и способам оплаты.
- Выгрузка отчёта выбранной смены в CSV.
- Журнал операций с возможностью отменить ошибочную продажу.
- Экспорт и импорт каталога или всех данных приложения.

## Работа со сменами

Кнопка **«Новая смена»** завершает текущую смену и начинает следующую. Накопленные продажи при этом не удаляются и остаются доступными на вкладке **«Итоги»**.

Для любой смены можно посмотреть отчёт и сохранить его в CSV. Завершённые смены также можно удалить; текущую смену удалить нельзя.

## Хранение данных

Все данные хранятся только в `localStorage` текущего браузера. Они не отправляются на сервер и не синхронизируются между устройствами.

Для резервного копирования на вкладке **«Настройки»** доступны:

- **«Сохранить список» / «Загрузить список»** — экспорт и импорт только каталога товаров;
- **«Экспорт всех данных» / «Импорт всех данных»** — полная резервная копия каталога, смен, продаж и журнала операций.

Периодически сохраняйте полную резервную копию: при очистке данных браузера или переустановке приложения локальные данные могут быть потеряны.

## Установка на телефон

Откройте [приложение](https://juriyivanov.github.io/gh/) в Chrome или Samsung Internet и выберите в меню браузера **«Добавить на главный экран»**. После первого открытия приложение можно использовать офлайн.

## Устройство проекта

Интерфейс и вся логика приложения находятся в одном файле `index.html`. Остальные файлы нужны только для установки и офлайн-работы PWA.
